# Contributors

Everyone listed under "Signed" has agreed that every contribution they make to this repository is made under the terms
of [LICENSE](LICENSE).

Ziad Sawalha (@ziadsawalha) and Jonas Frost (@icanhasjonas) own this repository and do not sign.

## How to sign

In your first pull request, add one commit, authored by you, that adds this line under "Signed", with your GitHub login:

```text
- @your-login: I agree that my contributions to this repository are made under LICENSE.
```

Use the commit message `chore(cla): agree to LICENSE as @your-login`.

The `CLA` check on every pull request fails until that line is on the base branch, or a commit you authored in the pull
request adds it.
